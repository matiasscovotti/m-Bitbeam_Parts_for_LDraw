# 🛍️ Sistema de Diseño para Ecommerce

Bienvenido al **Sistema de Diseño para Ecommerce** - una librería completa de componentes, bloques y templates optimizados para tiendas online modernas.

## 🎯 Objetivo

Crear una experiencia de compra excepcional con componentes reutilizables, accesibles y optimizados para conversión.

## 🧱 Arquitectura

### 📦 Componentes
Elementos individuales y reutilizables:
- **Button** - Botones con múltiples variantes y estados
- **ProductCard** - Tarjetas de producto con acciones rápidas
- **SearchInput** - Búsqueda inteligente con sugerencias

### 🔧 Bloques
Agrupaciones funcionales de componentes:
- **Header** - Navegación completa con búsqueda, carrito y menú
- **ProductGrid** - Grilla de productos con filtros avanzados

### 🏗️ Templates
Páginas completas listas para usar:
- **HomePage** - Página de inicio con hero, categorías y productos
- **ProductPage** - Página de producto con galería, variantes y reseñas

## 🎨 Características

- ✅ **Responsive** - Optimizado para todos los dispositivos
- ✅ **Accesible** - Cumple estándares WCAG
- ✅ **Modular** - Componentes independientes y reutilizables
- ✅ **TypeScript** - Tipado completo para mejor DX
- ✅ **Tailwind CSS** - Estilos utilitarios y personalizables
- ✅ **Storybook** - Documentación interactiva

## 🚀 Cómo usar

1. **Explora los componentes** en la barra lateral
2. **Interactúa con los controles** para ver variantes
3. **Copia el código** desde la pestaña "Docs"
4. **Adapta a tu proyecto** según tus necesidades

## 📱 Responsive Design

Todos los componentes están optimizados para:
- 📱 Mobile (375px+)
- 📱 Tablet (768px+) 
- 💻 Desktop (1024px+)
- 🖥️ Large (1440px+)

## 🎨 Paleta de Colores

- **Primary**: Azul moderno para acciones principales
- **Gray**: Escala de grises para texto y fondos
- **Success**: Verde para confirmaciones
- **Warning**: Amarillo para advertencias
- **Error**: Rojo para errores

## 🛒 Optimizado para Ecommerce

- **Conversión**: Botones y CTAs optimizados
- **Trust**: Elementos que generan confianza
- **UX**: Flujos de compra intuitivos
- **Performance**: Carga rápida y eficiente
